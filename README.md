# Climate response of tree radial growth to drought stress in Europe: a multi-site approach using ITRDB

Official repository for the paper *"Climate response of tree radial growth to drought stress in Europe: a multi-site approach using ITRDB"*.

## Repository Structure

- **R Package (`DESCRIPTION`, `NAMESPACE`, `R/`, `man/`)**: Contains the core `DendroCrhAn` R package, providing functions and tools to reproduce the main analytical workflow described in the paper.
- **`code/`**: Contains the full analysis in R Markdown format. *Note: Data required to run the scripts can be downloaded from the [Releases](../../releases) section of this repository.*
- **`paper/`**: Contains the manuscript files, figures, and publication material.
